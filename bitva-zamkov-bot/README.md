# HELLSTORM · Битва замков

Telegram-бот ордена **HELLSTORM**: свои сборки героев, справочник прокачки и удобное меню.  
Чужие гильдейские макеты и логотипы в проект не входят — оформление и тексты свои.

## Что умеет

- Постоянные кнопки внизу чата + вложенное меню
- 12 скринов сборок ордена с листанием
- Реликвии, кузница, божественность, экипировка, чары, сувениры, питомцы
- Поиск: напиши имя героя или тему (`террафика`, `реликвия`, `нарсия`)
- Ссылка на стикерпак

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), скопируй токен.
2. Нужен **Node.js 20+**.
3. В папке проекта:

```bat
copy .env.example .env
```

Вставь токен в `.env`:

```
TELEGRAM_BOT_TOKEN=123456:ABC...
```

```bat
npm install
npm start
```

В Telegram открой бота и отправь `/start`.

Не публикуй токен. С одним токеном одновременно должен работать только один процесс.

## Команды

| Команда    | Назначение        |
| ---------- | ----------------- |
| `/start`   | Меню              |
| `/guild`   | Об ордене         |
| `/builds`  | Сборки            |
| `/guide`   | Справочник        |
| `/help`    | Подсказка         |

Скриншоты сборок — материалы ордена HELLSTORM. Игровые цифры затрат сверяй с клиентом: патчи меняют таблицы.
