# HELLSTORM — Telegram-бот для «Битвы замков»

Бот с меню гильдии, сборками 12 героев, поиском по темам и справочником развития. Он работает через webhook на Cloudflare Workers, а не через постоянно запущенный процесс.

## Что умеет бот

- `/start` — открыть меню
- `/guild` — правила и краткая информация об ордене
- `/builds` — список героев и сборки из приложенных материалов
- `/guide` — справочник по прокачке
- `/help` — команды и поиск
- Поиск по обычному сообщению: например, «Террафика», «реликвия», «питомец», «Нарсия» или «чары»
- Кнопки для перехода между разделами и сборками

Данные и изображения взяты из архивов, приложенных владельцем проекта. Изображения персонажей и материалы игры остаются собственностью их правообладателей; бот не заявляет авторство на них. Эмблема в `assets/hellstorm-emblem.jpg` также предоставлена владельцем проекта. Перед публикацией убедитесь, что у вас есть право использовать все переданные изображения.

## Подготовка бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather), создайте бота командой `/newbot` и сохраните выданный токен. Никому его не отправляйте.
2. Если хотите поставить эмблему гильдии на аватар бота, загрузите `assets/hellstorm-emblem.jpg` через настройки бота в BotFather.
3. Загрузите **содержимое этой папки**, а не ZIP-файл как один файл, в новый репозиторий GitHub. Файл `.env` не добавляйте в репозиторий.
4. В Cloudflare откройте Workers & Pages и подключите GitHub-репозиторий как Worker. Для сборки используйте команду `npm run deploy`. Альтернатива — развернуть из этой папки командой `npm install` и затем `npm run deploy` после входа через Wrangler.
5. После первого развертывания скопируйте публичный HTTPS-адрес Worker из панели Cloudflare.
6. В Cloudflare откройте настройки Worker → Variables and Secrets и добавьте секреты:
   - `TELEGRAM_BOT_TOKEN` — токен из BotFather
   - `TELEGRAM_WEBHOOK_SECRET` — случайная строка из латинских букв, цифр, `_` и `-` (1–256 символов)

Сгенерировать секрет локально можно командой:

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
```

7. В этой папке скопируйте `.env.example` в `.env`, впишите те же два значения и адрес Worker:

```sh
cp .env.example .env
```

В Windows PowerShell используйте `Copy-Item .env.example .env`.

```env
TELEGRAM_BOT_TOKEN=токен_из_BotFather
TELEGRAM_WEBHOOK_SECRET=ваш_случайный_секрет
WORKER_URL=https://имя-worker.ваш-адрес.workers.dev
```

8. Установите локальные инструменты и зарегистрируйте webhook:

```sh
npm install
npm run configure
```

Скрипт не выводит токен и регистрирует команды `/start`, `/guild`, `/builds`, `/guide` и `/help`. Файл `.env` исключён из Git.

9. Проверьте адрес `https://имя-worker.ваш-адрес.workers.dev/api/health` — статус должен быть `ok`. Затем откройте бота и отправьте `/start`.

## Локальный запуск и обновление

Для локальной проверки Worker:

```sh
cp .env .dev.vars
npm install
npm run dev
```

В Windows PowerShell первая команда — `Copy-Item .env .dev.vars`. `.dev.vars` используется только локально и исключён из Git.

После изменения кода или материалов опубликуйте новую версию:

```sh
npm run deploy
```

Если адрес Worker меняется, обновите `WORKER_URL` в локальном `.env` и снова выполните `npm run configure`.

## Примечания

- Cloudflare нужен именно как **Worker с webhook**, а не как обычная статическая страница Pages.
- Токен не хранится в исходниках. Используйте секреты Cloudflare и локальный `.env`, который не включается в Git.
- Цифры расходов ресурсов в справочнике взяты из переданных материалов и могут устареть после игрового обновления.
- Стикер-ссылка настроена на набор, указанный в приложенных материалах.

Документация Cloudflare: [подключение GitHub к Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/git-integration/github-integration/) и [статические ресурсы Worker](https://developers.cloudflare.com/workers/static-assets/binding/).
