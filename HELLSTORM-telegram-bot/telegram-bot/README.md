# Telegram-бот гильдии HELLSTORM

Бот для игры «Битва замков» с разделом о гильдии HELLSTORM и каталогом из 12 сборок героев. Скриншоты сборок отправляются прямо в Telegram. В каждом списке и карточке героя есть ссылка на набор стикеров.

## Запуск в Replit

1. Создайте бота через [@BotFather](https://t.me/BotFather), если ещё не создали.
2. Добавьте выданный токен в секреты проекта под именем `TELEGRAM_BOT_TOKEN`.
3. Запустите workflow **API Server**. Бот работает через long polling.
4. Откройте бота в Telegram и отправьте `/start`.

## Запуск отдельно

Установите Node.js 20 или новее, затем из этой папки выполните:

```sh
npm install
```

Перед запуском задайте переменную окружения `TELEGRAM_BOT_TOKEN` (в Replit — через Secrets), затем выполните:

```sh
npm start
```

Не публикуйте токен и не добавляйте его в исходный код. Одновременно запускайте только один экземпляр бота с тем же токеном: Telegram разрешает одному токену только один активный long-polling процесс.

## Разделы

- `/start` — главное меню.
- «О гильдии» — принципы HELLSTORM, Нарсия и Высшая Лига.
- «Сборки героев» — 12 скриншотов с подписью о навыке и ссылкой на стикеры.

Скриншоты сборок предоставлены владельцем проекта.
